How to Read

— 読み方 —

本書は「ステップ・バイ・ステップ」形式で進む。各 mod は M.1 → M.7 のように番号化された章に分かれ、各章の下部に次章へのリンクがある。左サイドバーから任意の章へジャンプも可能だ。

Concatenation はレシピ改変が極端に多い pack である。本書の手順は標準 mod の挙動と Concatenation 独自の改変を統合したものだが、必ず in-game の EMI/JEI で実レシピを確認すること。Wiki に書かれているレシピが、Concatenation 内では別物に変わっていることが頻繁にある。

画像は各 mod の公式 Wiki / Fandom / Modrinth / CurseForge へのリンクとして表示される。画像クリックでオリジナルソースへ飛べる。

02Concatenation 独自の改変点— Caveats —

▲ 必読 — Concatenation での Mekanism 改変

Concatenation では Mekanism のレシピが 大幅に再バランスされている。標準 Mekanism Wiki の通りには進まない箇所が多い。

  • ◆ Mekanism機械は Supreme Machine Frame（Concatenation Core 製）必須
  • ◆ Mekanism鉱石生成は 無効化、原鉱石は Thermal 版に統一
  • ◆ Steel は Mekanism Infuser のほか、Tinkers smeltery / Brick Alloy Smelter / Thermal Induction Smelter でも作れる
  • ◆ Universal Cable と Mekanism Tank は Hand of Pentacles 必須に nerf（中盤以降の解放）
  • ◆ Coke はバニラ炉では作れない（Pyrolyzer / Coke Oven が必要）
  • ◆ Mekanism circuit に Silicon が必要に変更

03エネルギー単位の前提— Energy Foundation —

Mekanism のエネルギー単位は内部的に Joule (J) だが、Forge Energy (FE/RF) と 1:1 で相互変換される。表示単位は Configuration で切替可能（Mekanism Joules → kJ → MJ → GJ → TJ）。

Concatenation で Universal Cable は中盤まで作れないため、序盤は Pipez Energy Pipe や Powah Cable、または Thermal Fluxduct で機械に給電するのが標準ルート。

02Heat Generator の建造— Forging the First Engine —

Heat Generator は Mekanism 最初の発電機。溶岩源ブロックに隣接することで、燃料消費なしに passive 発電する。隣接する溶岩面の数で出力が線形に増え、最大 6面隣接 + 自身に Bucket of Lava で約 50–100 J/t。Concatenation 環境でもこの passive モードは健在で、序盤の主力電源となる。

レシピは中央に Furnace、その上下左右に Iron / Copper / Osmium 系を配置する 3×3 クラフト。EMI で「heat generator」と検索するとすぐ出る。

03建造の流れ— Step by Step —

  1. Osmium Ingot を 2 個確保
    鉄ピッケルで Osmium 鉱石を 2–4 個採掘 → 炉で焼く。Heat Generator のレシピは Osmium 1個だが、後続の Metallurgic Infuser でも使うので余裕を持って。
  2. Iron Ingot を 5–10 個確保
    Heat Generator のフレーム用に 3 個、後続の Infuser 用に 4 個、Cable 用にも数個必要。合計 10 個ほどあれば本章は完走できる。
  3. Copper Ingot 2 + Wood Plank 2
    Wood Plank はバニラ。Copper はバニラ Copper でも Mekanism Copper でもよい（タグ統合済み）。
  4. Furnace 1 個
    バニラ Furnace で OK。すでに持っているはず。
  5. クラフトテーブルで Heat Generator を作る
    配置：上段 Iron / Iron / Iron、中段 Copper / Furnace / Copper、下段 Wood / Osmium / Wood。正確な配置は EMI で再確認すること。
  6. 設置と溶岩配置
    安全な場所（できれば石ブロックで囲った発電室）に Heat Generator を置き、隣接面に溶岩源ブロックを配置。面が多いほど出力増。下面に置けば下から漏れる心配もない。
  7. 電力テスト
    Heat Generator に右クリックで GUI を開き、蓄電量が増えていくことを確認。J 表示でも FE 表示でも増加していれば成功。
◆ TIP — Heat Generator 多段配置
Heat Generator は複数並べて並列運用するのが Concatenation 流。1 台で 50 J/t は遅いが、4–6 台並べれば 200–300 J/t になり、Energized Smelter（200 J/t 消費）を回せる。溶岩は Industrial Foregoing の Pump（後の章で解説）か、Mekanism 自身の Electric Pump でネザーから引いて自動化できる。
▲ WARNING — Concatenation Core の Coal Generator との混同
Concatenation Core にも独自の Coal Generator があり、序盤に推奨されることがある。これは Mekanism の Heat Generator とは別物で、燃料に石炭を消費するシンプルな FE 発電機。クエストブックの指示に従って使い分けること。Heat Generator は溶岩 passive で長期運用向き、Concatenation Core Coal Generator は短期立ち上げ向き。
✦ ARCANE — Mekanism の隠された配線哲学
Mekanism のケーブル（Universal Cable）は Configurator という工具で各面ごとに「none / push / pull / both / disable」を切り替えられる。これは AE2 の Storage Bus や Pipez の Filter とは違い、機械側の出力面そのものを制御する仕様。Concatenation では Universal Cable が中盤まで使えないため、序盤は Pipez Energy Pipe + Filter で代用する。Pipez の Filter UI は Mekanism より直感的。

01Metallurgic Infuser の建造— The Infuser —

Metallurgic Infuser は Mekanism の「素材変換」の象徴たる機械。Iron Ingot に Carbon を注入して Enriched Iron を作り、もう一度注入して Steel Dust にする。Concatenation では Supreme Machine Frame が必須なので、純 Mekanism ルートを取る場合はこのフレームを先に作る必要がある。

03Steel 生成の手順— Forging the Steel —

  1. Coal を Enrichment Chamber で Enriched Carbon に
    ※ Enrichment Chamber は M.3 で作るが、本章で先取りしてもよい。Coal 1個 → Enriched Carbon 1個（Infuser 80回分の Carbon）を一度に格納。Infuser の Secondary slot に入れて使う。

    ※ 序盤の代替：Enrichment Chamber がまだなら、Coal をそのまま Infuser の Secondary に入れても OK（消費効率は悪い）。
  2. Infuser に Iron Ingot + Carbon を投入
    Primary slot（左）に Iron Ingot、Secondary slot（右）に Carbon を入れる。電力供給があれば自動で Enriched Iron が生成される。
  3. Enriched Iron を再度 Infuser に投入
    今度は Enriched Iron + Carbon で Steel Dust が出力される。
  4. Steel Dust をバニラ炉 / Energized Smelter で焼く
    Steel Dust → Steel Ingot。これで Mekanism の高位機械（Crusher、Purification Chamber 等）への道が開ける。
  5. 最低 8 個の Steel を確保
    M.3 の Energized Smelter（Steel×4 + Osmium×4 + Furnace）と Enrichment Chamber（Iron×4 + Redstone×2 + Osmium×2 + Steel×1） で計 5–9 個。残りは Cable やフレーム用に。
◆ TIP — Enriched Coal で 8 倍効率
Coal を Enrichment Chamber に通すと Enriched Coal になり、Infuser の Carbon 投入効率が 8 倍になる。Steel を量産するなら必須の前処理。Enrichment Chamber は M.3 で作るが、Steel 量産フェーズに入る前に必ず通すこと。
▲ WARNING — Concatenation での Steel レシピ確認
Concatenation では Steel のレシピが pack 独自に上書きされている可能性が高い。Mekanism Infuser 単体では作れず、Tinkers smeltery / Brick Alloy Smelter / Thermal Induction Smelter のいずれかが必要な構成になっているケースがある。必ず EMI で「steel ingot」を検索し、in-game レシピを確認すること。本章の手順は標準 Mekanism の挙動で、pack によっては該当しない場合がある。
✦ ARCANE — Brick Alloy Smelter（Concatenation 独自）
Concatenation Core 由来の Brick Alloy Smelter は、Tinkers Smeltery より小型で、Steel / Bronze / Constantan などの基本合金を作れる。序盤の合金製造の主役として設計されている。後継として Scorchia Alloy Smelter があるが、これは最近の更新で燃料効率が nerf されている。EMI で「alloy smelter」を検索すれば該当レシピが出る。

02最小2× ライン構築— The Minimum 2× Line —

  1. 配置プラン

  3. Energized Smelter を建造
    Steel×4 + Osmium×4 + Furnace×1。Mekanism 機械の中でも 消費電力が低く（200 J/t 程度）、Heat Generator 数台で十分回せる。

    Chest → Enrichment Chamber の入力面、Enrichment Chamber の出力面 → Energized Smelter の入力面、Energized Smelter の出力面 → Chest の順で並べる。機械の入出力面は Mekanism Configurator で確認・変更可能。デフォルトでは「正面が入出力」になっていることが多い。

    各機械の出力面と次の機械の入力面の間に Basic Logistical Transporter を 1–2 個配置。Configurator（Enriched Alloy + Lapis）で各端の 「Pull」「Push」「Default」「None」「Auto」を設定する。

    Heat Generator → Pipez Energy Pipe（中盤までの代替）→ Enrichment Chamber と Energized Smelter の電力面に接続。それぞれ 200–400 J/t 消費するので、Heat Gen が 2–3 台あれば十分。

    投入 Chest に raw_iron や raw_copper を入れる → Enrichment Chamber で dust×2 → Energized Smelter で ingot×2 → 出力 Chest に届く。これで 2× ore doubling が完成。

03建造手順— Step by Step —

  1. Crusher を作って M.3 ラインの後ろに増設
    M.3 の Enrichment Chamber 出力後ろに Crusher を挿入。Logistical Transporter で Enrichment → Crusher → Purification Chamber → Enrichment#2 → Energized Smelter の順に流す。
  2. 水源と Electrolytic Separator を設置
    Electrolytic Separator は水を入力として要求する。Mekanism Electric Pump（Energized Smelter と同等の素材で作れる）を水源に配置し、Mechanical Pipe（流体パイプ）で Separator に水を送る。または Bucket で手動補給も可。
  3. Pressurized Tube で O₂ を Purification Chamber へ
    Electrolytic Separator の左側（Output 1）が O₂、右側（Output 2）が H₂。O₂ 側に Pressurized Tube を接続し、Purification Chamber の気体入力面（紫タブ）へ繋ぐ。
  4. Purification Chamber と Enrichment Chamber #2 を連結
    Purification Chamber の出力（shard）を、2台目の Enrichment Chamber に渡す。shard → dust の変換が必要。Enrichment Chamber は M.3 と全く同じものをもう1台作る。
  5. H₂ を回収・備蓄
    H₂ は捨ててもよいが、Gas-burning Generator（Mekanism Generators）の燃料になるので、Mekanism Tank や Pressurized Tube + 終端 Tank に備蓄しておくと中盤の発電に使える。
  6. 電力強化
    機械が増えたので合計 1k J/t 程度必要。Heat Generator を 6–10 台並列するか、Stirling Dynamo / Magmatic Dynamo（Thermal）を併用するのが現実的。
  7. テスト稼働 — raw_iron が ingot×3 になることを確認
    投入チェストに raw_iron を入れて、出力チェストに iron_ingot×3 が出てくれば成功。3× ore doubling 完成。

04Factory ブロック化（推奨）— Factory Upgrade —

Mekanism には Factory ブロックがある。基本機械を Basic Factory（3 slot 並列）→ Advanced Factory（5 slot）→ Elite Factory（7 slot）→ Ultimate Factory（9 slot）にアップグレードできる。

Speed Upgrade（最大 8 個）と Energy Upgrade（最大 8 個）を入れることで、線形に速度UP・電力消費DOWNが可能。Speed 8 個でおよそ 10 倍速になるが、消費電力も急増するので Energy Upgrade も並走させること。

03建造手順— Step by Step —

  1. Thermal Evaporation Plant の建造
    multiblock。Thermal Evaporation Block（Iron×4 + Copper×4 + Osmium×1）を 4×4×3〜4×4×16 で枠組みし、内部に Thermal Evaporation Controller（GUI ブロック）を配置。Solar Panel または Heat Generator を上に置いて加熱。水 input は Thermal Evaporation Valve で受け取る。

  3. Chemical Infuser で HCl を合成
    Chemical Infuser の左入力に H₂、右入力に Cl₂。両気体が揃うと自動で HCl が出力される。これを Pressurized Tube で Chemical Injection Chamber に送る。

    M.4 ラインの Purification Chamber → Enrichment Chamber #2 の間に Chemical Injection Chamber を挿入。気体入力面（紫タブ）に HCl を Pressurized Tube で接続。出力は crystal（さらに Enrichment Chamber #2 で dust に戻して焼く）。

    投入チェストに raw_iron を入れて、出力チェストに iron_ingot×4 が出てくれば成功。4× ore doubling 完成。

02P2P Tunnel — 仮想多重化— Virtual Multiplexing —

P2P Tunnel（Point to Point Tunnel）は AE2 の魔法。1本のケーブルを仮想的に多数のチャンネルに多重化する。Dense Cable 経由で P2P を使うと、1本のCableで最大 32 種類の独立伝送が走る。

P2P Tunnel には Input（送信元）と Output（受信先）の対がある。Memory Card で送信元を「コピー」して、受信先に「貼り付け」ペアリング。1 Input → 多数 Output、または多数 Input → 1 Output どちらも可能。

◆ TIP — Dense Cable 経由が前提
P2P Tunnel は Dense Smart Cable（32 Channel）の経路上で使うのが標準。Glass Cable（8 Channel）経由でも動くが、Channel すぐ枯渇する。P2P 専用の Dense Cable Trunkを1本敷設して、そこから各 Subnetwork へ分岐するのが Concatenation 中盤の典型構成。

01Spatial IO — 空間 Storage— Storing Space Itself —

Spatial IO は AE2 の最も狂った機能。Spatial Pylon で囲まれた立方体空間を、Spatial Storage Cell（2³ / 16³ / 128³）に保存できる。出し入れすることで空間ごと建物を移動できる。

◆ 機械の電力残量も保存されるが、TileEntity 由来の cooldown は不安定

02建造手順— Step by Step —

  1. Energizing Rod を 4 本作る

02建造手順 — Coke + Blast の連結ライン— Connected Pipeline —

03List 操作の力— The Power of Lists —

ID の真の強みは List 操作。Inventory Reader が返すのは List<ItemStack>、Network Reader が返すのは List<Cable>、Entity Reader が返すのは List<Entity>。これらを map / filter / reduce で操作することで、データクエリ言語のように世界を扱える。

典型的な「在庫集計」関数：
① filter(items, isIngot)：インベントリから Ingot だけ取り出し
② map(item, getCount)：それぞれの数量を取り出し
③ reduce(counts, +, 0)：全数量を合計
これで「Ingot の総数」が得られる。SQL の SELECT SUM(count) WHERE type = 'ingot' と本質的に同じ。

02実用 Network の構築例— Practical Network —

例：「Mekanism Sulfuric Acid Tank が 50% 以下なら Pyrolyzer を起動」制御

  1. Mekanism Tank に Fluid Reader を貼り付け

    Logic Programmer で Boolean Variable を作成 → 「lessThan(div(amount, capacity), 0.5)」の式。Cable に Variable Store として挿入。
  3. Pyrolyzer に Redstone Writer を貼り付け
    Pyrolyzer の側面に Redstone Writer を貼る。Writer の入力に上で作った Boolean Variable を指定。Pyrolyzer の Redstone 制御モードを「On with signal」に設定。

    別の Cable 上に Display Panel を配置 → 入力に 「getAmount + ' / ' + getCapacity + ' mB'」のString Variable を指定。Tank 残量が常時表示される。

01SU と RPM の本質— Stress & Speed —

Create の動力は 2 つの直交する量で表される：

◆ SU（Stress Unit）：動力の「容量」。各機械が消費し、各動力源が供給。SU 不足で Network 停止。
◆ RPM（Revolutions Per Minute）：動力の「速度」。機械の処理速度に直接比例。Gearbox / Cogwheel で逓倍/逓減可能。

Mechanical Mixer は 16 SU @ 16 RPM 必要、Mechanical Press は 8 SU @ 16 RPM など。「SU 容量を増やす」=「動力源を増やす」、「RPM を増やす」=「Gearbox で逓倍 + 高速動力源」が基本戦略。

02Stress 拡張戦略— Capacity Strategy —

中盤以降、Stress 不足は機械単位で解決しない。動力源を Steam Engine の multiblockにスケールアップする：

  1. Boiler を multiblock 化
    Boiler は3×3 ベース + 高さ 4 でTier 4 Boilerになり、~16k SUを供給。下から Blaze Burner（Smoldering 状態）+ Fluid Tankで熱源と燃料供給。
  2. Blaze Burner を Smoldering 化
    通常 Blaze Burner はCoal で動くが SU が低い。Smoldering 状態（Liquid Lava + Blaze Cake で燃焼維持）にするとSU が 1 桁上がる。Concatenation の Pumpjack の Lava と組み合わせると永久。
  3. Liquid Fuel（Diesel / Heavy Oil）で持続化
    TFMG Distillery で取れる Heavy Oil / Diesel はBlaze Burner の高効率燃料。Coal より燃焼時間が圧倒的に長く、1 mB で数分間 Smoldering 維持。Pumpjack 経済と直結。
  4. Steam Engine 並列で SU 倍化
    Boiler 1 台に Steam Engine を最大 9 台並列接続可能。これで ~16k SU。さらに Boiler を2〜3 個並列すれば 30k SU 以上に達する。Concatenation 終盤の Create 機械群はこれで賄える。
◆ TIP — RPM の階層的逓倍
機械によって最適 RPM は違う。Mechanical Mixer は 16 RPM、Encased Fan は 256 RPM 推奨。Large Cogwheel + Small Cogwheel の組み合わせで2 倍 / 0.5 倍の変換、Gearbox で1:1 の方向変換。Network を「高速ライン」と「低速ライン」に二分するのが大規模 base の標準。
✦ ARCANE — Stress と Mekanism の電力哲学

02Laser IO の運用フロー— Operating Flow —

  1. 機械 / チェストに Laser Node を貼り付け
    全インベントリ機器の1 面に Laser Node を貼る。Mekanism 機械、AE2 ME Interface、IF Black Hole Unit など。1 機械 1 Node。
  2. Laser Connector で Node を接続
    各 Node 間を Laser Connector（中継ブロック）で接続。Connector は 1 個で複数 Node に接続可、ハブ的に使う。距離無制限・障害物無視。
  3. Card で動作を定義
    各 Node の GUI を開いて、各面の Card slotに Item Insert / Item Extract / Fluid Insert / Gas Insert / Redstone Send などを配置。「この面で Iron を吸い出して、向こうの Node の上面に挿入」のような明示的な指定。
  4. Filter Card で選別
    Item Card に Filter Card を紐付けて「Iron Ingot のみ吸い出す」のような選別。Mod ID マッチ可なので「Mekanism mod のアイテムだけ」みたいな指定もできる。
  5. Channel（色）で経路分離
    各 Card には16 色の Channelがある。同じ色の Card 同士でしか通信しないので、1 個の Connector を通る複数の経路を色で分離できる。これが Laser IO の論理的整理力の源。
◆ TIP — Laser IO の真価は Card の組み合わせ
Laser IO は「6 面 × 9 Card = 54 動作」を 1 ノードで処理できる。Mekanism 5x ライン全体を 1 個の Laser Node で制御するような芸当が可能。Pipez のように物理的に長いパイプを引かないので、base が劇的にコンパクト・整然とする。
